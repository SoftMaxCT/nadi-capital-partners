# Nadi Capital Partners Website

Static website for Nadi Capital Partners, hosted on GitHub Pages at [nadicapitalpartners.com](https://nadicapitalpartners.com).

## Structure

| Path | Purpose |
| --- | --- |
| `index.html` | The website: a single self-contained page that JavaScript renders in the browser |
| `assets/` | Favicon and Apple touch icon |
| `website_pic/` | Source images (logo and site photos) |
| `CNAME` | Custom domain for GitHub Pages |

## Deployment

GitHub Pages publishes the site automatically when changes are pushed to `main`. It always serves `index.html` as the homepage.
